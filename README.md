# Olá, eu sou Vitor Barbosa! 👋 | QA Analyst

## 🚀 Sobre mim

Analista de QA com **10 anos de experiência como Quality Gate**: validação de requisitos, regras de negócio e auditoria de processos no Ministério do Esporte e no CBCP. Hoje aplico essa mentalidade de qualidade e conformidade em **Teste de Software**.

Levei o olhar de auditor de processos para a qualidade de sistemas: casos de teste, matriz de rastreabilidade, bug reports bem documentados e, agora, **automação de testes Web, Mobile e API com Java**.

* 🔍 **Foco atual:** Testes funcionais e automação de testes Web, Mobile e API
* 🤖 **Automação:** Java + Selenium (Web), Appium (Mobile), RestAssured (API) e JUnit 5, com Page Object Model e CI no GitHub Actions
* 🧪 **O que eu faço:** Testes funcionais, regressivos, exploratórios e E2E | Casos de teste e checklists | Bug reports com evidências | Validação de contrato de APIs
* 🧠 **IA aplicada a QA:** uso assistentes de IA para gerar cenários de teste, massa de dados e apoiar a escrita de scripts, sempre revisando o resultado e sem expor dados sensíveis
* 🌱 **Estudando agora:** Appium avançado (gestos, iOS, device farm), Cucumber/BDD, Robot Framework e SQL avançado
* 💬 **Pergunte-me sobre:** Validação de requisitos, matriz de rastreabilidade, testes de API, Page Object Model, SQL
* 📫 **Contato:** vitoor.ads@outlook.com
